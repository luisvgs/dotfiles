* Phase 1: Foundations of Dependent Type Theory [0/4]
DEADLINE: <2026-04-08 Wed>

** TODO [#A] Rijke - Introduction to Homotopy Type Theory (Ch. 1-6)  :essential:foundations:
:PROPERTIES:
:AUTHOR: Egbert Rijke
:YEAR: 2025
:VENUE: Cambridge UP
:DOI: 10.1017/9781108933568
:URL: https://arxiv.org/abs/2212.11082
:FEEDS: Chapter 2 (Preliminares)
:END:
Solo capitulos 1-6. Cubre Pi types, Sigma types, identity types,
equivalences, truncation levels. NO leer los capitulos sobre HoTT/univalence.

** TODO [#A] Loh, McBride, Swierstra - A Tutorial Implementation of a Dependently Typed Lambda Calculus :essential:implementation:
:PROPERTIES:
:AUTHOR: Andres Loh, Conor McBride, Wouter Swierstra
:YEAR: 2010
:VENUE: Fundamenta Informaticae 102(2):177-207
:DOI: 10.3233/FI-2010-304
:URL: https://www.andres-loeh.de/LambdaPi/LambdaPi.pdf
:FEEDS: Chapter 3 (Core Language), Chapter 5 (Implementacion)
:END:
EL paper mas importante para arrancar la implementacion. Leer con el
codigo Haskell al lado. Replicar el LambdaPi como primer paso.

** TODO [#A] Mimram - Program = Proof (caps. lambda calculus, rewriting, dependent types) :essential:foundations:
:PROPERTIES:
:AUTHOR: Samuel Mimram
:YEAR: 2020
:URL: http://www.lix.polytechnique.fr/Labo/Samuel.Mimram//teaching/INF551/course.pdf
:ISBN: 979-8615591839
:FEEDS: Chapter 2 (Preliminares)
:END:
Usar como referencia de consulta. Cubre lambda calculus, rewriting
systems, y dependent types en un solo libro. Particularmente bueno
para rewriting (confluence, critical pairs, terminacion).

** TODO [#A] Coquand - An Algorithm for Type-Checking Dependent Types :essential:foundations:
:PROPERTIES:
:AUTHOR: Thierry Coquand
:YEAR: 1996
:VENUE: Science of Computer Programming 26(1-3):167-177
:DOI: 10.1016/0167-6423(95)00021-6
:FEEDS: Chapter 3 (Core Language)
:END:
El paper fundacional sobre type checking semantico para dependent
types. El algoritmo de Coquand es la base de todos los type checkers
modernos incluyendo Agda.

** TODO [#B] Christiansen - Checking Dependent Types with NbE: A Tutorial :recommended:implementation:
:PROPERTIES:
:AUTHOR: David Thrane Christiansen
:YEAR: 2019
:URL: https://davidchristiansen.dk/tutorials/implementing-types-hs.pdf
:FEEDS: Chapter 5 (Implementacion)
:END:
Tutorial en Haskell implementando "Tartlet" con NbE y bidirectional
checking. Mas moderno que LambdaPi, usa closures.

** TODO [#B] Norell - Towards a Practical Programming Language Based on Dependent Type Theory :recommended:implementation:
:PROPERTIES:
:AUTHOR: Ulf Norell
:YEAR: 2007
:VENUE: PhD thesis, Chalmers
:URL: https://www.cse.chalmers.se/~ulfn/papers/thesis.pdf
:FEEDS: Referencia estructural para la tesis
:END:
La tesis detras de Agda 2. Util como modelo estructural de como
escribir una tesis sobre implementar un lenguaje con tipos dependientes.

** TODO [#B] Dunfield, Krishnaswami - Bidirectional Typing            :recommended:implementation:
:PROPERTIES:
:AUTHOR: Jana Dunfield, Neel Krishnaswami
:YEAR: 2022
:VENUE: ACM Computing Surveys 54(5):1-38
:DOI: 10.1145/3450952
:URL: https://arxiv.org/abs/1908.05839
:FEEDS: Chapter 3 (Core Language)
:END:
Survey definitivo sobre bidirectional typing. Secciones 1-4
principalmente.

* Phase 3: Quotient Types -- Theory and Formalization [0/7]
DEADLINE: <2026-05-20 Wed>

** TODO [#A] Hofmann - Extensional Constructs in Intensional Type Theory :essential:quotients:
:PROPERTIES:
:AUTHOR: Martin Hofmann
:YEAR: 1995 (thesis), 1997 (book)
:VENUE: PhD thesis, U. Edinburgh / Springer
:DOI: 10.1007/978-1-4471-0963-1
:URL: https://ncatlab.org/nlab/files/HofmannExtensionalIntensionalTypeTheory.pdf
:FEEDS: Chapter 4 (Quotient Types)
:END:
Trabajo fundacional. Introduce el setoid model y el groupoid model.
Cubre proof irrelevance y quotient types. Seccion 2.3.6 sobre
quotient types es clave.

** TODO [#A] Barthe, Capretta, Pons - Setoids in Type Theory         :essential:quotients:
:PROPERTIES:
:AUTHOR: Gilles Barthe, Venanzio Capretta, Olivier Pons
:YEAR: 2003
:VENUE: JFP 13(2):261-293
:DOI: 10.1017/S0956796802004501
:URL: https://www.researchgate.net/publication/2409241_Setoids_in_Type_Theory
:FEEDS: Chapter 2 (Preliminares), Chapter 4 (Quotient Types)
:END:
Estudio comprehensivo de setoids. Muestra por que son dolorosos y
motiva la necesidad de quotient types reales.

** TODO [#A] Li - Quotient Types in Type Theory                      :essential:quotients:
:PROPERTIES:
:AUTHOR: Nuo Li
:YEAR: 2015
:VENUE: PhD thesis, U. Nottingham (supervisor: Altenkirch)
:URL: https://eprints.nottingham.ac.uk/28941/1/Nuo%20Li's_Thesis.pdf
:FEEDS: Chapter 4 (Quotient Types) -- REFERENCIA PRINCIPAL
:END:
La tesis mas directamente relacionada con el TFM de Luis. Cubre
definable quotients, setoid models, groupoid models, y HoTT.
Formalizado en Agda. LEER CAPITULOS 1-4 EN DETALLE.

** TODO [#A] Altenkirch, Anberree, Li - Definable Quotients in Type Theory :essential:quotients:
:PROPERTIES:
:AUTHOR: Thorsten Altenkirch, Thomas Anberree, Nuo Li
:YEAR: ~2011
:URL: https://people.cs.nott.ac.uk/psztxa/publ/defquotients.pdf
:FEEDS: Chapter 4 (Quotient Types)
:END:
Introduce "definable quotients" via normalization functions (split
coequalizers). Modelo conceptual detras de la implementacion de Lean.

:AUTHOR: Frederic Blanqui
